# ADR-008 — Fiction-only observational port, no production authority

**Accepted for Sprint 09, 2026-10-22.** Extends ADR-003/004; retention, manual WORKFLOW counters and all live gates remain unchanged.

The legacy `fictionalObserver` and JSON simulation protocol remain for existing regression/self-test flows. They are explicitly synthetic and can simulate selection; they are not the future observation contract. The new `adapters/read-only/contract.ts` describes only observed screening fields, displayed seat labels, explicit fictional provenance/time and compatibility. Its only status is UNKNOWN. No confirmed/selected/hold/account/geometry-verified variant exists. There is no conversion to legacy Observation, manual self-report or external evidence.

`fictional-reader.ts` is an internal experiment owned by packaged fixture.html; `fixture-reader.js` exports it for the native isolated-world test. Production adapter exports do not import/enable it. Scope permits only the actual package's exact fixture.html or the exact local renderer URL `http://127.0.0.1:4173/fixture.html`, no query/hash/subframe. LOCAL_PREVIEW is explicit and refused by the worker. Host-provided scope/world flags are test attestation, not authentication for any future production implementation. Real sender authority remains the Chrome-validated package/frame/document/tab/window/incognito binding.

The reader observes DOM mutations without writing DOM or dispatching events. It requires semantic plaintext visible fields; version/duplicates/hidden fields/canvas/errors/missing fields are conservative UNKNOWN/manual-only. A MutationObserver, synchronous takeRecords, pagehide/dispose, visibility recheck and a 30-second monotonic-age check invalidate snapshots. No remote request/retry, cookie/storage read, MAIN-world bridge, selector download or account inference exists. F10/F11 remain labels only, never availability/adjacency proof.

READONLY_BIND is an explicit fixture-only binding using the existing session registry. It returns an opaque, random per-binding receipt. READONLY_OBSERVE validates strict bounded output and the exact current binding object, per-worker receipt, reset version, B epoch, freshness and strictly increasing observation time. Rebind/navigation/reset/new worker/replaced buddy revoke the relevant receipt. B-bind requests also capture the B epoch before Chrome awaits, so a delayed bind cannot acquire a new receipt after the buddy/mode has changed. The worker acknowledges transport only and retains no interpreted screening/seat payload; it never changes simulation/manual evidence. At most two in-memory receipt records exist; no lease/storage schema in Chrome persists. Existing legacy BIND/OBSERVE stay isolated and are not upgraded to production trust. A compromised own extension bundle remains outside the protocol separation guarantee.

This design is not a production-content-script implementation or proof that Chrome can authenticate a caller's claimed world. The native test creates a real CDP ISOLATED world solely on our own ZIP-installed fictional page, imports the packaged parser and checks it cannot see a MAIN-world sentinel. It proves that limited design in that environment; no scripting/debugger permission is added to the shipped manifest. User-facing lab runs in its own trusted extension page and truthfully labels that provenance. A future real observer requires G0, a separate reviewed port/permission diff and explicit authorization; production origins stay empty, DISABLED_G0.
