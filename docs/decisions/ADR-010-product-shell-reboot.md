# ADR-010 — Compact official-site handoff, optional developer tools

Accepted, Sprint 12 / issue #27, 22 October 2026. Supersedes the default navigation in ADR-005/007, not their safety, worker, storage or B-only invalidation contracts.

The owner installed and rendered 0.10.1 on Mac but rejected its usability. Green simulation/checklist tests did not establish product value. The default popup and Side Panel now share `ProductShell.vue`: one static `https://www.vuecinemas.nl/` anchor, zero required fields, one small help/privacy disclosure and a separate closed **Ontwikkelaarstests** disclosure. There is no showing-reference input: without reading the official source it would duplicate work. No empty A/B cards or guessed account binding. The ordinary link opens a new tab from the user's click with `noopener noreferrer`; it needs no host/tabs/scripting permission and does not create an independent login session.

Legacy popup/planner components are lazy-mounted only after the developer disclosure is intentionally opened. Closing keeps the mounted local forms to preserve unsaved concepts, pauses their timers and returns focus to the official-site action. Opening/closing never sends RESET or changes consent. Pending responses remain bounded by the existing four-second transport timeout, operation guard and Vue-scope disposal; no mutation replay. Explicit developer context refreshes still re-observe worker replacement and B epochs. Hidden UI is not an authorization boundary: sender validation and storage restrictions remain in the worker.

The simulation transport reuses `useCompanion` instead of maintaining a second protocol client. Passive `isRefreshing` cannot disable controls; actual `isSubmitting` still does. Both popup and panel clients ignore replies after scope disposal or after a superseding action. No opacity masking. [FAIL→PASS evidence](../security-review-sprint12.md).

The only new flow experiment is `QuickTicketPrototype.vue` on the existing fictional page: preset exact showing → already eligible physical pair → independent A/B review acknowledgements. Three meaningful actions, no forms, storage, messages, new backend or booking status. It reuses the existing strict ZERO EXTRA engine. Thirty-second expiry or clock reversal clears both reviews. It never yields real availability, account or zero-fee evidence. Older adapter/map laboratories remain available for regressions.

Architecture ideas from external projects are recorded in [the dated decision](../vue-integration-decision-2026-10.md); no third-party source/assets or new dependency incorporated. A real provider, normalized current evidence, ranking and official booking handoff are separate responsibilities. A production provider is intentionally absent. Adding one requires actual terms/permission evidence, separate owner authorization and narrowly scoped Chrome permissions. No dormant site-injection code ships.

The compact shell is a baseline convenience, not a two-tab killer. **PRODUCT_VALUE NO-GO** until the same real task measurably improves. Stop speculative administrative features; prefer an officially supported read-only path, otherwise stop/pivot. [Benchmark](../ux-reset-benchmark.md).
