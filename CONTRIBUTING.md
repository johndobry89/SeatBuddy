# Contributing

Thanks for helping make two independent cinema visits easier to coordinate.

1. Read [AGENTS.md](AGENTS.md), [SEATMATES_MASTERPLAN.md](SEATMATES_MASTERPLAN.md) and [docs/feasibility.md](docs/feasibility.md).
2. Open an issue or focused PR. Keep changes small and test observable outcomes.
3. Use **fictional, sanitized** fixtures only. No screenshots containing real accounts, tickets, names or identifiers.
4. Run the repository's documented scripts **after those scripts exist**. Report actual verification performed, not assumed tests.
5. Never implement payment/final booking automation, credential handling, bypasses or unapproved site interactions.
6. Explain deviations from an ADR with a new design decision. Keep G0 unmarked until real evidence exists.

This project is independent of Vue Cinemas and is not endorsed by them.
